Video sources

When launched from DVB-I with ?interpreter=... (or ?main=...), the app uses those URLs — streams come from DVB-I, no local files needed. When opened standalone, it falls back to videos/main.mp4 and videos/interpreter.mp4 (put files in videos/, run from a local server). Override via the fields below or URL params. See docs/STREAMS_FROM_DVBI.md and README.
