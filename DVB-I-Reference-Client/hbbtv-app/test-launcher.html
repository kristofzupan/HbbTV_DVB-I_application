DVB-I + HbbTV test launcher

Ensure both servers are running: DVB-I backend (9080) and HbbTV app (8080). Then open:

  • HbbTV app (8080)
    Dual video + interpreter overlay (uses videos/main.mp4, videos/interpreter.mp4 if present)
  • HbbTV app – interpreter-only (stream from DVB-I)
    Shows only overlay; main area says “Main content is on the TV”
  • DVB-I frontend (9080) – HTML5 player
    Select “Thesis accessibility list”, then channel 1
  • DVB-I backend – service list editor (9080)
    Edit service lists (e.g. thesis.xml)
